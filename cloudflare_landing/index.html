Yes. MONOLITH is built from the ground up for air-gapped environments. The Ollama local daemon, vector RAG embeddings, and AST linting run entirely on your local CPU/GPU with zero external telemetry. If browser automation or external scraping is required, the developer can explicitly toggle the Sovereign Boundary Egress authorization.

MONOLITH's browser engine attaches a network response listener to Playwright Chromium while resolving the pin URL. It sniffs high-bitrate MP4 streams directly from the network payload or DOM data scripts (with automated web downloader fallback), streaming the raw binary chunks into your local output/downloads/ workspace folder with SHA-256 verification.

Session cookies are stored locally in session_vault/ and encrypted using AES-256-GCM authenticated encryption. Keys are derived per-host, and raw cookie files are excluded from git tracking. The browser engine injects decrypted cookies only into isolated Playwright contexts in memory.

MONOLITH runs smoothly on modern commodity hardware: a minimum of 8 GB RAM and a 4-core CPU (Intel i5/Ryzen 5 or Apple Silicon). Discrete GPUs (NVIDIA RTX with CUDA) further accelerate inference, but are not required thanks to 4-bit quantization in Ollama.
